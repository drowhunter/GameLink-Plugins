Until Dawn: Rush of Blood

Rush of Blood is a PS4 / PSVR game. It runs on PC through BloodRush, an unofficial build of the shadPS4 emulator (2D desktop and PC-VR) that streams the cart's motion (speed, orientation and G-forces) over UDP.

Get the emulator

  1. Download the latest BloodRush release here (project page). Use a release from b002 or newer; earlier builds don't send telemetry.
  2. Extract it and follow the release instructions. No game files are provided, so you must dump your own copy of the game.

Play

  1. Select this game in GameLink and press Start.
  2. Launch Rush of Blood with BloodRush's shadps4.exe (desktop or pc-vr).
  3. Ride. Motion is applied while the cart is in play. When the game is paused or between rides, the motion platform holds its position.

Notes

  • Orientation uses the game's Y-up axes: yaw about Y, pitch about X, roll about Z. Yaw is an absolute heading in degrees; GameLink handles its wrap at +/-180 degrees.
  • Pitch and roll are scaled to the configured device limits, not its maximum capabilities. Keep Pitch inverted as in the default profile: pitch scaling accounts for this inversion so final forward output uses PitchLimitF and backward output uses PitchLimitB. Roll uses RollLimit in both directions. Custom multipliers, offsets or axis inversion changes can alter the final range.
  • If upgrading from the original default profile, update the motion mappings in your saved profile: Yaw (input 1) to Yaw, Pitch (input 2) to Pitch, and Roll (input 3) to Roll. The original default profile had Pitch and Roll outputs crossed. Existing saved profiles are not changed by replacing the DLL.
  • Telemetry is sent to 127.0.0.1:25151 by default (matches the plugin's default IP and port settings).
  • Telemetry is on by default. It is disabled if the environment variable SHADPS4_ROB_MOTION_TELEMETRY=0 is set.
  • You do not need to run the BloodRush_telemetry Python bridge. The plugin reads the UDP feed directly. The port is shared, so the bridge can still run alongside the plugin for other motion software.
