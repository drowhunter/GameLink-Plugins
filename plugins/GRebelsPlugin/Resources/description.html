Setup

G-Rebels has built-in motion telemetry. No mod or patch is required.

  1. Launch G-Rebels and open the Options menu.
  2. Turn on Telemetry.
  3. In the telemetry settings, uncheck the Positive Speed option.
  4. Start GameLink. The game sends telemetry to UDP port 33001 on this PC.

Notes

  • The game does not send angular velocity. The plugin calculates AngularVelocityX (pitch), AngularVelocityY (yaw) and AngularVelocityZ (roll) from the change in rotation between packets.
  • The plugin also calculates Bump (size of vertical acceleration) and Slide (size of sideways velocity). The default profile uses them for rumble (AMP and HZ), and uses Speed for the fan (SPlug).
  • RPM, Gear, suspension travel and wheel terrain are part of the packet but G-Rebels always sends them as 0.
  • Other SimRacingStudio-compatible apps can listen on port 33001 at the same time.
