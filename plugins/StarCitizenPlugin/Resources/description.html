Star Citizen

Star Citizen sends motion telemetry through D-BOX's LiveMotion connector. SC-Motion-Haptic-Bridge receives it and forwards every game event as JSON over UDP; this plugin reads those events directly, so SimHub is not needed.

Setup

  1. Install SC-Motion-Haptic-Bridge and follow its install guide (D-BOX HaptiSync Center, certificate setup).
  2. Make its capture server SC_Motion_Server.py also send to this plugin's port, 127.0.0.1:61703.

Play

  1. Start the capture server (or the bridge's Start StarCitizen - Motion Enabled launcher).
  2. Select this game in GameLink and press Start.
  3. Launch Star Citizen and take a pilot seat. Motion only runs while you are seated in a vehicle.

Notes

  • The motion inputs are the same values the bridge sends to SimHub (rates in deg/s, velocities in m/s), with the same landed gate, glitch hold, stale ramp and seat gate. Accelerations (Surge/Sway/Heave) are in m/s² and are not scaled by the bridge's 0.1.
  • The game sends no orientation, so Yaw is a heading accumulated from the yaw rate.
  • Impact is a 0..1 pulse for collisions, explosions, touchdowns and hull/shield hits. Speed, EngineRpm, Throttle, EngineOn, Boost and OnGround are available for effects.
