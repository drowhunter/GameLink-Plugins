X-Wing Virtual Machine (XWVM)

XWVM is a free fan-made engine that remakes the classic LucasArts X-Wing on Windows. It has built-in motion telemetry and sends JSON over UDP while you are in flight.

Get the game / mod

  1. Get the latest XWVM installer from the official XWVM Discord. Use a build that has Settings > Telemetry. The engine needs your own copy of X-Wing (Collector Series / GOG / Steam); no game files are provided.
  2. In XWVM open Settings > Telemetry. Turn broadcasting on, set Format to JSON, address 127.0.0.1 and port 10555.

Play

  1. Select this game in GameLink and press Start.
  2. Launch xwvm.exe.
  3. Start a mission. Telemetry is only sent while you are flying.

Notes

  • Telemetry is sent to 127.0.0.1:10555 by default (matches the plugin's default IP and port settings).
  • JSON is recommended: it includes ship orientation (Yaw/Pitch/Roll). XWVM currently ignores the saved Format on startup and sends SimHub until you change the dropdown in-game, so after launching set Format to SimHub and back to JSON. SimHub packets are also accepted, but carry only rates/accelerations (Yaw/Pitch/Roll inputs stay at 0).
  • Lower the broadcast interval (default 0.1 s = 10 Hz) for smoother motion.
